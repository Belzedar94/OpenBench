The queue, by account

One shared queue. Each account advances by the nodes it already has queued, so the first request of a newcomer is served before the thousandth of a heavy user, and a big batch interleaves instead of walling the queue. Running a worker gives exactly one scheduling advantage: while it runs, it serves its owner's requests first.
