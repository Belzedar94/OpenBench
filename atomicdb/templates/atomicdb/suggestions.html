Opening name suggestions

Visitors propose a name where a position has none (NEW), or a correction to the name a position already shows (EDIT, written as current → proposed), or ask for a position to have no name (HIDE NAME, with their reason). Approving one publishes it on that position as a community name, or hides the name it shows. A NEW or an EDIT may carry a move order, and approving it makes that the line links to the name take.

Move orders ({{ routes_total }})

The line every link to a name opens the position by, instead of whatever order the tree reached it first. Without one, a catalogue name takes its catalogue line. Give the moves from the start position in SAN or UCI; the position can be left empty, and the line's last position is the one named. Every position along the line is added to the tree.
