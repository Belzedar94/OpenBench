Contributing and attribution

You can help with or without hardware, and every analysis is credited to the account that delivered it.

Two ways to help

  • Without hardware: every unsolved position has a request button, and that request rides the same queue as everything else. No account or worker needed. See Request analysis.
  • With a computer: contributing compute needs an account and the worker. The instructions for both are on the method page.

How credit is counted

  • Every completed analysis records the authenticated account that delivered it, and the boards on the front page group by that stamp.
  • Machine names are chosen by the worker, and two accounts can announce the same one, so attribution never rests on a machine name where it can be avoided.
Older analyses
  • Rows older than the account stamp fall back to the machine map, and only for unambiguous machines: a disputed name attributes to nobody.
  • Those nodes still count for the fleet, because they were really searched, and the page says openly what belongs to nobody.
